# Shhh Brightness Toggle 1.0.0 (Minecraft 1.20.1 Forge) Release Notes

Initial release of Shhh Brightness Toggle for Minecraft 1.20.1 on Minecraft Forge.

## Features
- Fullbright Toggle: Press B (default) to turn brightness on and off while playing.
- Brightness Adjustment: Press Up Arrow to increase brightness and Down Arrow to decrease brightness in 10% steps (from 10% to 100%).
- Safe & Clean: Operates via non-destructive in-memory lightmap scaling. Does not modify options.gamma or options.txt.
- Colored Feedback: Dynamic actionbar messages shifting from red at low levels to warm gold and soft green at maximum.
- In-Game Config Screen: Accessible via the Forge Mod List ("Config" button) or by typing `/shhh` in chat.
- Client-Side Only: Runs entirely on your client and does not need to be installed on servers.

## Requirements
- Minecraft: 1.20.1
- Minecraft Forge: 47.1.0 or newer (tested on 47.3.0)
- Java: 17 or newer

## Server Rules Warning
Some multiplayer servers do not allow fullbright or brightness adjustment mods. Check your server rules before using this mod online. Use at your own risk.
